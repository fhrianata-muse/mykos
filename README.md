# MyKos

Platform pencarian dan booking kos online — konsepnya seperti platform booking perjalanan (cari, bandingkan, booking, bayar, dapat kode booking), diterapkan untuk sewa kos bulanan.

## Untuk siapa

- **Penyewa** — cari kos berdasarkan kota/kampus, tipe, dan bujet; bandingkan harga, fasilitas, foto, dan ulasan; booking dan bayar online; terima kode booking untuk check-in.
- **Pemilik kos** — pasang listing, kelola harga dan ketersediaan dari satu dasbor, terima booking dari penyewa terverifikasi. Gratis memasang listing; biaya layanan hanya dari booking yang berhasil.

## Isi halaman demo

- Pencarian dengan filter kota, tipe kos, tanggal masuk, durasi, dan harga maksimal — hasilnya langsung menyaring katalog.
- Katalog 9 kos contoh di 7 kota, dengan filter fasilitas (AC, kamar mandi dalam, WiFi, parkir, dapur, laundry) dan urutan harga/rating.
- Detail kos dalam dialog: fasilitas, aturan, biaya, sisa kamar, dan tombol booking demo.
- Alur booking 4 langkah, area populer yang bisa diklik untuk menyaring, formulir pendaftaran pemilik kos, dan FAQ soal pembayaran dan perlindungan kedua pihak.

Data kos, harga, rating, dan ulasan di halaman ini adalah contoh untuk mendemonstrasikan konsepnya.

## Teknologi

HTML, CSS, dan JavaScript murni tanpa framework. Font Plus Jakarta Sans. Buka `index.html` di browser, atau kunjungi versi online lewat GitHub Pages.
